# 第一批正式结果：三靶点 60 设计 / 靶点（2026-11-16）

数据：BoltzGen 0.3.2，Colab L4，三个靶点各 60 个设计（`num_design=90`），单次运行、单种子。
脚本：`analysis/first_batch_stats.py`　统计表：`analysis/first_batch_descriptives.csv`
原始 CSV（`{bnp,anp,scr}_all_designs_metrics.csv`）尚未入库，见文末「数据归档」。

所用分数均为**模型自己的置信度，不是亲和力**。排序分数 `design_to_target_iptm`，辅以 `min_design_to_target_pae`（越低越好），另报 `design_to_target_ipsae`。
**`quality_score` 是批内秩归一化，跨靶点不可比，本文不使用；`design_ptm` 批间漂移大于其自身 SD，不使用。**

## 一句话结论

这套未经修改的流程，**连「打乱序列的假靶点」都没有压低分数**。scr 的 iptm 均值 0.3325，和 bnp（0.3232）、anp（0.3322）实质相同，三者的差都远小于已测的噪声底 ±0.05。既然连阴性对照都分不出，BNP vs ANP 的那点差（−0.009）就根本没有解读空间。

## 1. 数据健康度

三份 CSV 各 60 行，`num_design` 全为 90，三个关键指标无缺失值，设计序列无重复。数据可用。

## 3. 阴性对照（最要紧的一问）

**scr 没有被压下去。**

- iptm：scr − bnp = **+0.0093**，scr − anp = **+0.0003**。Cohen's d 分别 0.06 和 0.002；Mann–Whitney 双侧 p = 0.99 和 0.50。
- pae：scr 的均值（8.59）比两个真靶点**还略低**（即「更好」），差 0.3–0.4，d ≤ 0.10，p ≥ 0.67。
- ipsae：scr 均值（0.0278）**高于**两个真靶点，anp vs scr d = −0.57（p = 0.158）——方向上阴性对照反而拿到更高的 ipSAE。

唯一有结构的差别在**离散度**：scr 的 iptm SD 0.179，明显大于 bnp 0.136 和 anp 0.112，分布两头都更厚（既有 0.09 的，也有 0.74 的最高分）。也就是说，打乱序列并没有让分数系统性变低，只是让它变得更不稳定。

这条和 Smorodina 等人在非同源阴性对上的结论方向一致（ipTM 的判别力接近随机），但这里的阴性是**同一条序列打乱**，已经是最容易被识别的假靶点了。

## 4. BNP vs ANP

- iptm：差 **−0.0090**（bnp 低），d = −0.07，p = 0.36。噪声底是 ±0.05 → **差值只有噪声底的五分之一，不构成任何证据**。
- pae：差 −0.08，d = −0.02，p = 0.94。
- ipsae：差 +0.0078，d = +0.40，p = 0.26（bnp 偏高，但不显著，且 ipsae 的绝对值都在 0.03 以下，见下）。

**结论：在这批数据里，流程的置信度分数不区分 BNP 和 ANP。** 需要写清楚的限制：n=60、单次运行、单种子，p 值只是描述性的，没有做多重比较校正；噪声底本身是 n=20 测的，SE≈0.024。

## 5. ipSAE 复现（Junker & Schoeder）

`design_to_target_ipsae` 三组的中位数都在 0.008–0.013，绝大多数设计接近 0，最大值也只有 0.20。按 ipSAE 原文的尺度，这批设计基本全是「没有可信界面」的量级——而 iptm 却给出 0.32 的中位水平。两个分数给出的图景不一致，且 ipSAE 同样没有把阴性对照分开（方向还反了）。这正是 Junker 报告的失败模式，这里算是在新体系上的复现。

## 6. 这对课题意味着什么

**这是结果，不是失败。** 计划里写明「有选择性或没有选择性都成立，只有没数据才算失败」。现在拿到的是一个更强的陈述：

> 未经修改的 BoltzGen + Boltz-2 打分流程，其置信度分数不仅无法区分高度同源的 BNP 与 ANP，连打乱序列的阴性靶点都无法区分。

要让这句话站得住，还差两件事（都不在这次范围内）：

1. **交叉打分表**——把为 BNP 设计的 binder 拿去给 ANP 打分、反之亦然。这才是直接测「选择性」的实验，上面只是测「每个靶点各自能拿多高分」。
2. **外部标尺**——Overath 等 2025 的 436 个有湿实验标签的 de novo binder，用来确认「分数分不开」不是我们这套跑法的问题。

另外值得记一笔：既然 scr 的最高分（0.7425）比两个真靶点都高，那么「按 iptm 挑 top-N 送去做实验」这个在领域里默认的做法，在这个体系里挑出来的会有相当比例是噪声。

## 7. 未解决 / 待确认

- 噪声底是在哪个靶点上测的、是否对 scr 同样适用（scr 的 SD 更大，可能需要单独测一次）。
- 是否补一个同源性更低的第三真靶点（CNP），原计划推迟到一月。
- 本批只跑了一个种子。要把「分不开」写进论文，至少需要第二个种子重复一次，证明这不是某一次采样的偶然。
